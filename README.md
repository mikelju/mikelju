## 🚀 Featured work

### 📚 [LLM Context Systems — Engineering Portfolio](https://github.com/mikelju/llm-context-systems-portfolio)

**RAG · Retrieval · Context Engineering · Document Intelligence · Agentic Workflows**

An evidence-backed portfolio documenting real AI systems designed around the hardest part of applied LLM engineering: getting the **right information and tools into the model's context**.

Sanitized artifacts, system traces, technical decisions, trade-offs and runnable offline demonstrations.

> **Focus:** hierarchical retrieval · metadata-first retrieval · multimodal RAG · agentic document Q&A · deterministic tooling

---

### 🎙️ [Voice-to-Order](https://github.com/mikelju/voice-to-order)

**FastAPI · PostgreSQL · pgvector · Docker · Python · LLMs**

A fully anonymized, locally runnable replica of a production voice-ordering system.

<div align="center">

<img src="https://raw.githubusercontent.com/mikelju/mikelju/main/voice-to-order-architecture-clean.svg" alt="Voice-to-Order architecture" width="100%" />

</div>

The system combines a large product catalogue with **learned reference memory built from previously confirmed orders**, improving recognition of customer-specific terminology, abbreviations and informal descriptions.

---

### 🔬 [Concept Embeddings RAG](https://github.com/mikelju/concept-embeddings-RAG)

**Information Retrieval · RAG · LLM Evaluation · Python**

A retrieval research experiment exploring corpus-induced concept spaces and iterative retrieval as alternatives to conventional dense retrieval.

The project compares retrieval strategies under a fixed context budget and is built around **measurable evidence, reproducible baselines and explicit evaluation** rather than a demo-only RAG application.

## 🧩 How I think about AI systems

**Models are only one part of the system.**

I focus on the layer around them: what information to retrieve, what context to provide, which tools to call, what should remain deterministic, and where human validation is needed.

### Engineering principles

> **Right context > more context**  
> **Deterministic when possible**  
> **Evaluate before optimizing**  
> **Human validation where it matters**
