## Selected work

### [LLM Context Systems — Engineering Portfolio](https://github.com/mikelju/llm-context-systems-portfolio)

An evidence-backed engineering portfolio focused on the layer between LLMs and real company information: retrieval, context selection, document intelligence, agentic workflows and deterministic tooling.

Real client/internal systems are documented through sanitized artifacts, system traces, technical decisions, trade-offs and runnable offline demonstrations.

### [Voice-to-Order](https://github.com/mikelju/voice-to-order)

A fully anonymized, locally runnable replica of a production voice-ordering system.

Voice/text input is transformed into structured orders, matched against a ~31k-row catalogue and learned reference memory, reviewed by a human and delivered through business-process integrations.

**Stack:** FastAPI · React · PostgreSQL · pgvector · Docker · Python · LLMs

### [Concept Embeddings RAG](https://github.com/mikelju/concept-embeddings-RAG)

A retrieval research experiment exploring corpus-induced concept spaces and iterative retrieval as alternatives to conventional dense retrieval.

The project compares retrieval strategies under a fixed context budget and is built around measurable evidence rather than a demo-only RAG application.
